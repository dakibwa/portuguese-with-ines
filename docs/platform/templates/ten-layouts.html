Ten layouts

Every tutor picks a layout and a colour set. Here are the ten layouts, each with a made-up tutor in its own colours, at desktop and phone width. Scroll inside a screen to see the whole home page, and switch any of them to another colour set.

Ten colour sets

Each set is eleven named roles: page, card, wash, text, quiet text, line, brand, action and two paints. Every layout uses only those roles, so all 100 combinations work. Each set is checked so that every pair of text and background a layout uses clears 4.5:1.

How they plug into the platform

  • Two settingsThe tutor record gets look: { layout, palette }. Inês is atelier with porto, which draws her site exactly as it is today.
  • One booking systemBooking, payments, a student’s lessons and the tutor’s schedule stay one shared set of parts. A layout only gives them its type, corners and edges, as in each Find a time card above, so a release tests ten skins, not ten booking systems.
  • Any tutor’s wordsEach layout reads the same content: the hero line, three principles, an about, an optional photo, the FAQ and lesson prices from the booking system. A layout may add one optional feature of its own (Grid’s table, Lexicon’s entry, Postcard’s note) and must look right without it, with short or long text, and with two lessons or six.
  • SwitchingColours change for free at any time. Changing layout keeps every word, so it is safe to try; the fee only applies when the tutor wants new photos or pages reworked.

Every tutor, price and student quote on this page is made up to show the layouts. Inês’s site is the only real one, and it is Atelier in Porto colours.
