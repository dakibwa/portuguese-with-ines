# PastLessons

Lessons already had, newest first, each with what was paid.

**Markup:** `.unified-account-area` with the account menu's places (Your lessons, Past lessons, Homework, Edit details) as one sliding control, then `.past-lessons` cards.

- Each lesson is a `raised` tile with its mark, the long date (breaking before its year, never leaving the time alone on a line) and a small status pill (`Paid`, `Charged`, `Paid by hand`) that keeps the pill's own size.
- Two columns where they fit; one on a phone.
