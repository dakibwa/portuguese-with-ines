# PhoneTimetable

Inês's timetable on a phone: the days as a row of dates, one day's hours beneath.

**Markup:** as Timetable, at phone width.

- Today's date is the blue tile; dots mark days with lessons. A lesson block keeps its name, time and Meet button; nothing is cut off.
