# ScheduleProfile

Inês's Profile tab: her name, sign-in email and password, each with one small action.

**Markup:** `.teacher-account` card with rows of a label, a value in `lavender-ink`, and a small outline button (`Sign out`, `Change email`, `Send reset link`).

- One `sheet` card at the hint sizes; rows part with a 1px `rule-soft`.
- Errors here use `warning-ink`.
